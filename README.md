# QUALISaP-PNAISP — Qualificação em Saúde Prisional

Página de apresentação do curso de qualificação em saúde prisional da Fiocruz: objetivo, módulos e matriz curricular. Uma página só, em HTML, CSS e JavaScript.

## Abrir

Abra `index.html` no navegador, ou sirva a pasta:

```bash
python -m http.server 8000
```

Acesse <http://localhost:8000/>.

## Estrutura

```
index.html    a página
css/          estilos
js/           scripts
image/        logos
```

## Publicar

Copie os arquivos para o servidor. Não há build.

## Homologação

Não há ambiente de homologação.
